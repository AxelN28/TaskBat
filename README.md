# TaskBat

TaskBat es una aplicación web Full Stack
para la gestión de tareas.

## Tecnologías

- Frontend: React + Vite
- Backend: Node.js + Express
- Base de datos: PostgreSQL
- Control de versiones: Git y GitHub
- Despliegue: Render

## Estructura

- backend/: API REST
- frontend/: Interfaz de usuario
